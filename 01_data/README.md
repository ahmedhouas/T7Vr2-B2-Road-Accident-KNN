# Data

This directory contains the dataset files used in the project.

## Directory Roles

- `raw/`: immutable source data. Raw files must not be edited or overwritten.
- `interim/`: intermediate transformations produced during data preparation.
- `processed/`: cleaned, encoded, or otherwise analysis-ready datasets.

Do not commit credentials or personal or sensitive data. Record dataset
provenance, license, expected shape, and preprocessing changes in this README
or in the relevant project documentation.
